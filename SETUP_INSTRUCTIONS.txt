# AI-Assisted SIEM Threat Detection Platform — Setup Instructions

## 1. What's in the zip

```
splunk-soc-dashboard/
├── siem_dashboard.xml        # Main Splunk dashboard (deploy this)
├── setup_monitor.sh          # Configures Splunk to auto-index logs from a folder
├── generate_test_logs.sh     # Creates test logs with today's date
├── sample_auth.log           # Static sample auth/sudo/SSH logs
├── generate_mock_data.sh     # (Optional) HEC-based mock event generator
├── index.html                # (Optional) Static mock dashboard for Cloudflare Pages
└── README.md                 # Full documentation
```

## 2. Requirements

- Splunk Enterprise installed at `/opt/splunk`
- A Linux machine (Kali tested)

## 3. Setup (run these 3 commands in order)

```bash
# 1) Extract the zip and enter the folder
unzip splunk-soc-dashboard.zip
cd splunk-soc-dashboard

# 2) Deploy the dashboard
sudo mkdir -p /opt/splunk/etc/apps/search/local/data/ui/views/
sudo cp siem_dashboard.xml /opt/splunk/etc/apps/search/local/data/ui/views/siem_dashboard.xml

# 3) Set up log monitoring + restart Splunk
sudo bash setup_monitor.sh
```

## 4. Add test data

```bash
# Generate a fresh test log (dated today)
bash generate_test_logs.sh

# Index it automatically
sudo cp test_auth_20260806.log /var/log/splunk-monitor/test_auth.log
```

Wait ~30 seconds, then open the dashboard:

```
http://localhost:8000/en-US/app/search/siem_dashboard
```

## 5. Adding your own logs later

```bash
sudo cp yourfile.log /var/log/splunk-monitor/
```

Splunk indexes it automatically into `index=main sourcetype=save`.

## 6. Demo script (5 minutes)

1. Open dashboard — show 4 KPI cards (what happened)

3. Show Recent Events table (the parsed logs)
4. Show MITRE ATT&CK Mapping (the highlight — T1110, T1078, T1548)
5. Read the AI Summary out loud (auto-generated from real data)

## 7. Common issues

| Problem | Fix |
|---------|-----|
| Dashboard 404 | Re-deploy XML and restart Splunk. XML must be valid (no raw `&` in "ATT&CK"). |
| All zeros | Data not indexed. Run `index=main | stats count by sourcetype` in Search. |
| Timeline flat | Logs too old. Regenerate with `bash generate_test_logs.sh`. |

Full details in README.md.
